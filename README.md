# Дизайн-токены: презентация

Доклад о том, как устроены дизайн-токены: от выгрузки из Figma до сборки приложения — и почему решение именно такое.

Собрана на [reveal.js](https://revealjs.com). Главная особенность: **презентация свёрстана на настоящих токенах системы**, про которую рассказывает.

## Запуск

```bash
npm install
npm start
```

Откроется `http://localhost:8000`. Можно и просто открыть `index.html` — всё локальное, из сети подтягиваются только шрифты.

| Клавиша | Что делает |
| --- | --- |
| `→` `←` | следующий и предыдущий блок |
| `↓` `↑` | слайды внутри блока |
| `S` | заметки докладчика |
| `Esc` | обзор всех слайдов |
| `F` | полный экран |

## Заметки докладчика

В `aside class="notes"` у каждого слайда лежит **дословный текст выступления**, а не тезисы: можно читать с экрана докладчика как есть. Открывается клавишей `S` — во втором окне рядом с текущим и следующим слайдом.

## Токены вместо палитры

`css/design-tokens.css` сгенерирован скриптом из документа релиза `1.0.0` — 84 базовых литерала и 145 продуктовых алиасов, со всей двухслойностью системы:

```css
--base-color-violet-500: #7000ff;        /* base-b2b: литерал */
--accent-brand: var(--base-color-violet-500);  /* product: алиас */
```

`css/deck.css` не содержит ни одного своего цвета, радиуса или отступа — только обращения к этим переменным. Шрифт тоже из системы: `typography.*.fontFamily` → Wix Madefor Display. Единственная добавка — масштаб: токены рассчитаны на интерфейс, а слайд смотрят с пяти метров, поэтому кегли и отступы домножаются на коэффициент.

Поэтому слайд «две коллекции» показывает настоящие плашки: то, чем покрашена сама презентация.

### Пересобрать токены

Если на стенде вышел новый релиз:

```bash
# выгрузить документ релиза
docker exec -e PGPASSWORD=... data-engine-postgres \
  psql -U postgres -d data_engine -At \
  -c "select document from dyn_design_data_token_release_payloads limit 1" > doc.json

python3 tools/tokens-to-css.py doc.json css/design-tokens.css
```

Скрипт берёт режим `b2b-light`. Для тёмной темы поменяйте константу `MODE` на `b2b-dark` — вёрстка не изменится, потому что имена продуктовых токенов те же.

## Мемы

Шаблоны с imgflip, подписи свёрстаны поверх картинки в HTML — текст живёт в `index.html` и правится как обычный текст.

| Файл | Слайд | Шутка |
| --- | --- | --- |
| `drake.jpg` | проблема | копировать hex руками / одна команда в CI |
| `boyfriend.jpg` | alias-only | продуктовый токен засматривается на литерал |
| `two-buttons.jpg` | неизменяемость | поправить выпущенный релиз / выпустить новый |
| `panik.png` | ожидаемый хеш | токен поменяли во время публикации |
| `this-is-fine.jpg` | заморозка канала | дизайнер публикует, продакшен заморожен |
| `doge-cheems.png` | чтения как данные | ноль строк кода / рукописный роут |
| `always-has-been.png` | пакет | «подключить токены — это одна команда?» — «всегда ею и было» |

Заменить мем: положите файл в `dist/assets/memes/` и поправьте `src` у нужного `<img>`. Позиции подписей — классы `cap-tr`, `cap-br`, `cap-top`, `cap-bottom`, `cap-l`, `cap-r`, `cap-p1..p3` плюс модификатор `plain` для тёмного текста на светлой части шаблона.
